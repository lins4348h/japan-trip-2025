# 教師退休現金流工作坊（3 小時）

| 檔案 | 用途 |
| --- | --- |
| `../open-slide-workspace/slides/teacher-retirement-cashflow/index.tsx` | open-slide 簡報原始檔（42 頁，含講者備註與每頁時間） |
| `簡報預覽_教師退休現金流工作坊.pdf` | 簡報靜態預覽 |
| `worksheet.html` | 學習單原始檔（可直接改字，瀏覽器列印 A4） |
| `學習單_我的退休帳本.pdf` | 學習單列印版（5 頁 A4） |

## 啟動簡報
```bash
cd open-slide-workspace
npm install
npm run dev   # 開 http://localhost:5173/s/teacher-retirement-cashflow ，按 F 全螢幕
```
