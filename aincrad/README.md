# 艾恩葛朗特 — Headless Blender 程序化 3D 場景

以純 Python（Blender 的 `bpy` 模組，無 GUI）生成的巨型浮游城場景，靈感取自《刀劍神域》的浮游城「艾恩葛朗特」。
所有幾何、材質、燈光皆為**程序化生成**，不使用任何外部模型或貼圖，單一指令即可重建整個世界。

---

## 場景規模

| 項目 | 數值 |
|---|---|
| 浮游城直徑 | 12.2 km（底層半徑 6,100 m） |

| 樓層數 | 100 層完整環狀樓層 |
| 第一層（英雄樓層） | 620 m 挑高，含完整地形、城鎮、湖泊、迷宮塔 |
| 場景物件 | 約 9,600 個物件 / 340 萬面（high 品質） |
| 建置時間 | 約 50 秒（4 核 CPU） |

## 安裝與使用

```bash
pip install bpy==4.5.13          # Blender 4.5 LTS 的 Python 模組（需 Python 3.11）
```

### 建構場景

```bash
python3 build_aincrad.py --quality high --blend out/aincrad.blend
```

`--quality` 可選 `draft`（快速預覽）／`high`（預設）／`ultra`（最高細節）。

### 算圖

```bash
# 全部 17 個鏡頭
python3 build_aincrad.py --quality high --render --samples 96 --width 1920 --height 1080

# 指定鏡頭（用編號前綴）
python3 build_aincrad.py --quality high --render --shots 01,04,08 --samples 128
```

輸出在 `renders/`。算圖引擎為 Cycles（CPU），已開啟自適應取樣與 OpenImageDenoise。

### 怎麼打開場景檔（不需要寫任何程式）

1. **裝 Blender**：到 [blender.org/download](https://www.blender.org/download/) 下載 4.5 LTS 或更新版（免費，Windows／macOS 皆可），一路下一步安裝完成。
2. **拿檔案**：直接用本專案的 `aincrad/aincrad_scene.blend`（已壓縮，20.7 MB）。
3. **開啟**：雙擊該檔，或開 Blender 後 `File → Open` 選它。第一次載入約需 10–30 秒。
4. **看鏡頭**：按 `Numpad 0` 進入攝影機視角。要換鏡頭，在右上角 Outliner 點選想要的攝影機（例如 `05_town_aerial`），再按 `Ctrl + Numpad 0`。
5. **自由飛行**：把滑鼠移到 3D 視窗中央，按 `` Shift + ` ``（Esc 下面那顆鍵）進入飛行模式 → `W/A/S/D` 前後左右、`E/Q` 上升下降、移動滑鼠轉向、滾輪調整速度、左鍵確認、`Esc` 取消。
6. **顯示模式**：右上角四顆小球，由左到右是線框／實體／材質預覽／算圖預覽。大場景先用**實體**最順，想看材質再切材質預覽。
7. **筆電沒有數字鍵盤**：`Edit → Preferences → Input → 勾選 Emulate Numpad`，之後用主鍵盤的 `0` 就等於 `Numpad 0`。
8. **跑不動時**：Outliner 裡把 `01_Exterior`（百層外殼）眼睛圖示關掉，室內瀏覽會快很多。
9. **想出圖**：按 `F12` 算目前攝影機的畫面。CPU 算圖很慢（1600×900 約 5–10 分鐘），算完在該視窗 `Alt + S` 存檔。

### 自由探索

用 Blender 開啟 `aincrad/aincrad_scene.blend`（或自行建構的 `out/aincrad.blend`）：

- `` ` ``（重音符）→ 選 **Fly/Walk Navigation**，或按 `Shift + ~` 直接飛行；`W/A/S/D` 移動、滑鼠轉向
- `Numpad 0` 切換攝影機；場景已內建 17 台命名攝影機（見下表）
- Outliner 內的集合可單獨隱藏：`01_Exterior`／`02_Terrain`／`03_Vegetation`／
  `04_Town`／`05_Dungeon`／`06_Interiors`／`07_Lights`
- 進入室內時，把 `01_Exterior` 隱藏可大幅加快視窗更新

## 程式結構

```
build_aincrad.py        CLI 進入點
aincrad/
├── config.py           全域尺度、樓層公式、品質分級
├── meshutil.py         程序化幾何核心（旋轉面、放樣、擠出、掃掠、雜訊）
├── materials.py        62 種全程序化材質（石砌、木紋、金屬、水、植被、發光）
├── blutil.py           Blender 物件與實體化（instancing）輔助
├── exterior.py         環狀樓層、外殼、扶壁、城底倒錐、中央主塔、浮空島、雲
├── nature.py           地形高度場、湖河、樹木／岩石／草叢散佈
├── town.py             城牆、城門、街道、廣場、建築生成器、城堡、訓練場、橋、遺跡
├── dungeon.py          迷宮塔、石牆迷宮、地下城入口、神殿、Boss 房間
├── props.py            中世紀奇幻室內道具庫
├── interiors.py        房間殼體、酒場、工坊
├── scene.py            場景組裝、世界、光線連結、人造天空
├── cameras.py          17 組鏡頭
└── render.py           Cycles 設定與批次出圖
```

### 幾點技術做法

- **實體化（instancing）**：樹木、建築、橋樑共用 mesh datablock，5,200 棵樹只佔數千面的記憶體。
- **光線連結（light linking）**：內、外兩顆太陽以 `light_linking.receiver_collection` 分離，
  外部黃昏斜射不會污染樓層內部，樓層內部的高角度太陽也不會照到外殼。
- **人造天空**：第一層天頂是一片發光面（`sky_ceiling`），並設 `visible_shadow = False`，
  讓內部太陽的陰影能正常投射；天頂另有一個高亮圓盤模擬「人造太陽」。
- **剖面缺口**：以帶缺口的旋轉面（`ring()` 支援多道角度缺口）取代布林運算，
  零布林、零非流形，並自動補上厚實的斷面牆。
- **地形查詢**：`nature.Terrain.height()` 是可向量化的解析式高度場，
  地表網格與所有散佈物件共用同一函式，因此物件永遠貼合地面。
