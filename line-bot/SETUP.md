# 行政訊息轉譯 Bot — 架設步驟

全部免費，除了 Anthropic API 的用量費（一次整理約 0.2～1.2 元，看模型）。
從頭到尾大約 30 分鐘。

---

## 一、建立試算表與程式

1. 到 [sheets.new](https://sheets.new) 開一份新的 Google 試算表，命名為「行政訊息轉譯」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的 `function myFunction() {}` 全部刪掉，貼上 `Code.gs` 的完整內容。
4. 按 💾 儲存。

先不要執行，設定還沒填。

---

## 二、申請 LINE Bot

1. 到 [developers.line.biz](https://developers.line.biz/console/) 用 LINE 帳號登入。
2. 建立一個 **Provider**（名稱隨意，例如你的名字）。
3. 在該 Provider 底下 **Create a new channel → Messaging API**。
   - Channel name 就是 Bot 在 LINE 裡顯示的名字，例如「聯絡事項小幫手」
   - 類別隨意選，之後可改
4. 建好後切到 **Messaging API** 分頁，拉到最下面的 **Channel access token (long-lived)**，按 **Issue**，複製那一長串。

### 把自動回覆關掉（很重要）

同一頁往上找到 **Auto-reply messages** 和 **Greeting messages**，點旁邊的 **Edit** 會跳到 LINE Official Account Manager：

- **自動回應訊息** → 停用
- **加入好友的歡迎訊息** → 停用（可留，但會多一則罐頭訊息）
- **Webhook** → 啟用

沒關掉的話，你每傳一則訊息都會收到一句「感謝您的訊息！」。

---

## 三、申請 Anthropic API key

1. 到 [console.anthropic.com](https://console.anthropic.com) 註冊。
2. **API keys → Create key**，複製那串 `sk-ant-...`。
3. 到 **Billing** 儲值一點額度（最低額度就能用很久）。

---

## 四、填設定、部署

回到 Apps Script，把最上面設定區的兩個值填好：

```javascript
const LINE_TOKEN = 'LINE 的 Channel access token';
const ANTHROPIC_KEY = 'sk-ant-...';
const OWNER_USER_ID = '';   // 這個先留空
```

然後：

1. 右上角 **部署 → 新增部署作業**
2. 齒輪圖示 → 選擇 **網頁應用程式**
3. 設定成：
   - 執行身分：**我**
   - 誰可以存取：**任何人**　←　必須是這個，否則 LINE 連不進來
4. 按 **部署**，第一次會要求授權，一路允許（中間會出現「Google 尚未驗證這個應用程式」，點「進階 → 前往...」）
5. 複製最後給你的 **網頁應用程式網址**（`.../exec` 結尾）

---

## 五、接上 Webhook

1. 回到 LINE Developers 的 **Messaging API** 分頁
2. **Webhook URL** 貼上剛剛那串 `/exec` 網址，按 **Update**
3. 按 **Verify**，出現 Success 就對了
4. 確認 **Use webhook** 是開啟的

---

## 六、認人

1. 用手機掃 Messaging API 分頁上的 QR code，把 Bot 加為好友
2. 傳「**我是誰**」給它
3. 它會回一串 `U` 開頭的 ID，複製起來
4. 回 Apps Script，填進 `OWNER_USER_ID`，儲存
5. **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**

> ⚠️ 每次改程式碼都要做第 5 步。只按儲存是不會生效的，這是最常踩的坑。

---

## 七、試跑

在 LINE 裡傳幾則假的行政訊息給 Bot，例如：

```
教務處 林組長：本週五(9/12)第七節英語會考，請帶2B鉛筆。
學務處 陳主任：校外教學同意書9/15前收齊，費用380元。
教務處 林組長：更正！英語會考改到第八節，14:10開始。
```

然後輸入「**整理**」。

順利的話，你會收到四則訊息：一則摘要與待辦，接著學生版、簡化版、家長版各一則——**每一則都可以長按 → 轉傳 → 直接丟進班級群組**。

回頭看試算表，會多出「暫存」「待辦」「紀錄」三個分頁，待辦已經存進去了。

---

## 平常怎麼用

| 你做的事 | 結果 |
|---|---|
| 在行政群組長按訊息 → 選取多則 → 轉傳給 Bot | Bot 安靜收下，不回話 |
| 輸入「整理」 | 回四則：待辦摘要＋三個布達版本 |
| 長按學生版 → 轉傳 → 班群 | 布達完成，全程沒有複製貼上 |
| 輸入「待辦」 | 列出未完成的事 |
| 輸入「完成 3」 | 第 3 項打勾 |
| 輸入「清空」 | 轉傳錯了就丟掉重來 |

## 選配：每天早上提醒

Apps Script 左側 ⏰ **觸發條件 → 新增觸發條件**：

- 函式：`dailyReminder`
- 事件來源：時間驅動
- 類型：日計時器
- 時間：早上 7 點到 8 點

每天早上 Bot 會主動推一則「今天還有 N 件事」。

推播訊息會計入 LINE 免費方案的每月額度（目前是 200 則），一天一則綽綽有餘。回覆你的訊息不算在內。

## 想調整的地方

程式碼最上面的設定區：

| 常數 | 作用 |
|---|---|
| `DEFAULT_CLASS` | 學生版標題的班級名稱 |
| `MODEL` | 想省錢改 `'claude-haiku-4-5'`，約十分之一價格 |
| `EFFORT` | `'low'` / `'medium'` / `'high'`，調高比較準但比較慢 |

改完記得重新部署（管理部署作業 → 編輯 → 新版本）。

轉譯的規則寫在 `buildPrompt()` 裡，想改語氣、加欄位、調整簡化版的字數上限，都改那裡。

---

## 出問題時

| 症狀 | 通常是 |
|---|---|
| 傳訊息完全沒反應 | Webhook URL 沒更新到最新版本，或忘了「新版本」部署 |
| 回一句「感謝您的訊息」 | 自動回應訊息沒關掉 |
| 回「整理失敗：API 回應 401」 | Anthropic API key 填錯 |
| 回「整理失敗：API 回應 400」 | 通常是額度用完，到 Console 的 Billing 看 |
| 整理很久才回，或回了兩次 | 正常，太慢時會自動從「回覆」切成「推播」。想快一點就把 `EFFORT` 調成 `'low'` |

看詳細錯誤：Apps Script 左側的 **執行項目**，點進去看記錄。

---

## 兩件要記得的事

**這是只給你自己用的版本。** 別人傳訊息會被擋掉。要開放給同事需要另外處理身分與費用，先自己跑兩週再說。

**訊息會經過你的 Google 帳號和 Anthropic。** 學生姓名、家長聯絡方式如果出現在行政訊息裡，都會被存進你的試算表。自己用還好，開放前要想清楚。
